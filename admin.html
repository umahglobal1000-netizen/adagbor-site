Register members

Type or paste one name per line. You can add a phone number after a comma, for example Rabiu Dankadiri, 08012345678. Each new member is approved straight away. Choose Register and generate PINs to give them PINs now, or Register only to add them without PINs and generate PINs later, when required, in the Generate a PIN section below. Members log in with their surname and PIN.

Generate a PIN

An existing PIN cannot be looked up, because only a scrambled copy is stored. Instead, generate a new one: tick the members who need a PIN (or select everyone without one) and generate. A new PIN replaces the old one straight away and is added to the PIN list at the bottom of this page.
